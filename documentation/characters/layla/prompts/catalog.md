# Layla event image catalog

Every Layla event with a prompt spec. This is the human-readable source; `script/gen-layla-event-images.sh` is the runnable script that feeds these into the Codex CLI pipeline.

## Shared references (all events)

- **Face reference**: `~/Pictures/common-people-mod-images/Layla/layla.png`
- **Style reference**: `~/Pictures/common-people-mod-images/Layla/cp_layla_homesteading.dds.png`
- **Palette**: warm ochre, sienna, cream; deep red accents (wax, pomegranate sky); painterly oil canvas texture; 19th-century genre painting register.
- **Aspect**: 3:2 landscape, target 600×400.
- **Mahfouz register**: quiet, specific, sensory, subtext. A witness's eye, not a narrator's. No heroic poses; no dramatic gestures. Light and composition do the work.
- **Age discipline**: Layla is 22 in 1836. For events clearly in Act IV–V, render her older. For Act I, render her young. Default: mid-30s if ambiguous.

Each entry: `Output — Title — Context — Scene — Mood`.
