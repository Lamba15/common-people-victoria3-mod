# Common People -- Narrative Research Library

This directory contains historical research for writing authentic event text. Each file covers a region or theme. Use these as reference when writing events for specific countries.

## By Region
- [egypt.md](egypt.md) -- Egypt: fellahin, corvee, cotton boom/bust, Suez Canal, women, slavery, Tahtawi, Urabi, British occupation, labor history
- [middle-east.md](middle-east.md) -- Persia, Ottoman heartland, Iraq, Syria/Lebanon, Arabia, Yemen, Palestine, Central Asia
- [europe.md](europe.md) -- France, Germany, Italy, Ireland, Spain, Austria-Hungary, Scandinavia, Poland, Greece, Balkans
- [russia.md](russia.md) -- Serfdom, emancipation, factory life, Bloody Sunday, 1905 revolution
- [asia.md](asia.md) -- India, China, Japan, Southeast Asia, Pacific
- [americas.md](americas.md) -- Mexico, Brazil, Argentina, Cuba, Haiti, Peru, Colombia, Chile, Canada, USA
- [africa.md](africa.md) -- West Africa, East Africa, Southern Africa, Congo, Ethiopia
